# 用户指南

## 资料库和文件夹

手写笔记与 Markdown 各自管理文件夹。点击文件夹展开，拖入文稿，或将文稿拖到移出区域或上一级目标。废纸篓提供恢复、永久删除和清空。

Ctrl+F 聚焦资料库搜索，Esc 先清除搜索，再关闭文件夹。搜索标题时会搜索当前类别下的内容，无需逐个打开文件夹。普通列表、搜索列表与各个文件夹分别记住滚动位置，打开文稿后返回时恢复浏览位置。

封面取自首页，顶部对齐并铺满卡片。首页内容变化后会重新生成封面，生成期间显示底图和等待标记。

## 文档内打开其他文稿

文稿切换菜单先列出已打开文稿，当前项显示勾选。选择“按文件夹打开文稿”打开资料库选择器：文件夹逐级进入，用上一级和根目录按钮返回；搜索跨文件夹查找标题，并显示所属路径。选择后保存当前文稿并打开目标，取消或关闭不会切换。

此选择器只显示手写/PDF 文稿及其文件夹，不混入 Markdown；Markdown 编辑器有自己的标签和快速打开入口。

## 文稿外观和侧栏预览

文稿右上角可以切换跟随系统、浅色或深色。主画布、页面缩略图和书签缩略图共用同一显示规则。深色模式会调暗普通浅色导入页。自己选定的纸张模板始终按本色显示。

在「更改纸张模板」里应用新纸张后，当前页和侧栏一起刷新。模板页上的已有黑白字迹和文字会随纸色调整显示对比，彩色墨迹和嵌入图片保留原色。换纸保留笔迹的撤销历史。自动对比用于编辑器预览，文稿保存、导出和「截取当前页」仍使用保存的墨色。

## 文字输入与调整

文字工具点击纸面放置文本框。默认字号 12，可自定义字号；输入面板尺寸以屏幕为基准，不随画布缩放而变成巨大的工具条。

输入面板的文字、光标和提示使用主题配色。提交时保存所选文字颜色，画布和侧栏再按文稿外观显示。

Ctrl+Enter 或完成按钮提交，Esc 取消。已有长文本通过属性窗口编辑，保留全文并支持字体与宽度调整。“适应页面”查找避开已有内容的位置，必要时缩小，低于可读阈值时提示；空间完全不足时不强行覆盖现有笔迹。定位动画帮助确认文本移动到了哪里。

## 撤销、只读与导航

切页、关闭文稿或执行依赖已保存内容的操作时，如果写入失败，FastInk 会保留当前笔迹和撤销历史并显示保存错误。恢复写入权限或腾出磁盘空间后，可按 Ctrl+S 重试。

文档中 Ctrl+Z 撤销笔迹和对象操作，Ctrl+Y 或 Ctrl+Shift+Z 重做。Ctrl+C、Ctrl+X、Ctrl+V 复制、剪切和粘贴，Ctrl+D 生成副本，Delete 或 Backspace 删除选区，Esc 取消选区。画布和工具栏共用这些键位。页码或文字输入框使用自己的剪贴板和历史。只读、页面加载或持有笔迹锁时限制编辑。

点击页码后全选，按 Enter 跳页并返回画布焦点。空输入或离开输入框时恢复当前页码。超出范围的数字定位到首页或末页。

F11 切换全屏，Esc 退出全屏。页面/目录/书签侧栏可收起和恢复。PDF 自带目录与手工章节标题共同显示，没有目录的扫描件不会自动获得目录或 OCR。

## 截图、标注和粘贴图片

点击工具栏左侧固定的「选择截图区域」，用触笔或鼠标左键拖动。可拖动范围内部移动，或拖动边界把手调整大小。截图窗口忽略手指触摸。

截图中的笔侧键沿用文稿设置，包括绑定动作、侧键交换、按住临时切换和按一次切换。绑定橡皮时擦除标注，绑定框选时选择或拖动标注。钢笔使用文稿笔型和压感，荧光笔与橡皮各有独立参数。裁切区域由「选择截图区域」按钮管理。

截图和文稿共用撤销、重做、删除和生成副本的键位。用「选区」点选标注，Ctrl+C 复制，Ctrl+X 剪切，Ctrl+V 粘贴。Esc 先取消选中，再按关闭截图。用「复制图片」或 Ctrl+Shift+C 把截图范围合成为系统剪贴板图片。Ctrl+S 另存 PNG，Enter 插入文稿。

“插入当前页”和文稿内 Ctrl+V 粘贴图片，都会把图放到当前页的可见区域并选中。鼠标、触笔和单指可直接抓住选中的图片移动，用边角与旋转柄调整大小和方向。手指从选区外开始滑动时浏览页面。

## 笔尖压感

在“设置 → 手写笔记”的笔输入区打开笔尖压感。拖动灵敏度或更改曲线时，预览即时显示当前笔型在轻、中、重三档压力下的相对粗细。灵敏度越高，轻按越容易变粗。曲线和灵敏度用于新写的笔迹。钢笔、画笔和铅笔有压感，圆珠笔使用固定粗细。

## 导入、转换和导出

PDF 按需生成显示页，保留原文件供搜索、目录和导出复用。图片可批量导入为页面。导入 OneNote 的 `.one`、`.onex`、`.onepkg` 需要本机安装 OneNote 桌面版。可提取的文字、图片和笔迹会转为 FastInk 可编辑对象，导入报告列出跳过的内容。

资料库卡片导出以整本文稿为范围；文档内可选整本或当前页。导出显示进度，耗时依赖内容与设备。跨文稿复制页位于批量页面管理中，按源页序追加到目标末尾，保留原文稿。

## 自动供电模式

Windows 供电状态约每 2 秒检测一次。电池或系统节电模式自动采用经济策略；接入电源后自动恢复相应预算，不需要手动开关。

电池模式降低屏幕底图和预览的解码预算，合并小显示瓦片，减少装饰效果与预取。侧栏笔迹读取与 PDF 缩略图任务等待书写、手势和滚动空隙；相同可见范围合并排队，关闭侧栏、离开文稿后取消尚未启动的旧任务。已执行的外部渲染可能完成当前页，不会为了停止预览而结束其他应用。

保存和导出使用原始笔迹数据，撤销历史继续独立管理。
