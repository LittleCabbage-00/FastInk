# 设置

资料库设置分为「通用」「手写笔记」和「Markdown」。Markdown 编辑器内的设置与资料库的 Markdown 分类共用。

| 分类 | 设置范围 |
| --- | --- |
| 通用 | 显示语言、主题、工具提示、资料库状态栏、存储位置、备份、Windows 右键菜单、关于 |
| 手写笔记 | 压感、笔侧键、书写工具、框选、文本框、页码、保存、侧栏、手势、PDF、激光笔和内存 |
| Markdown | 编辑输入、排版、预览、导出、本地历史 |

## 手写笔记

- 压感曲线和灵敏度用于后续落笔，设置页会显示三档压力对应的线宽。圆珠笔使用固定粗细。
- 笔侧键动作、按住切换和交换键位同时用于文稿与截图标注。截图区域通过「选择截图区域」调整。
- 默认文本字号用于新文本框，页面角标立即更新。仅笔书写仍允许用鼠标框选与拖动对象。
- 自动保存开关控制延迟写入。按 Ctrl+S、切页或关闭文稿时也会保存。
- PDF 导入分辨率用于生成显示页。原 PDF 独立保存。
- 内存档位控制预览与笔迹缓存的预算。系统供电变化时自动调整屏幕渲染和预取。
- 清理临时缓存会移除可重新生成的预览和后台缓存。

## Markdown

视图、输入、排版、导出和本地历史选项见 [Markdown 工作台](markdown-workbench.md)。目录、专注、打字机与同步滚动可在编辑器内切换，待办列表内可隐藏已完成项。

## 存储

资料库位置存放文稿、资源和索引，配置位置存放偏好。可在通用设置内移动资料库，或手动创建和恢复备份。
