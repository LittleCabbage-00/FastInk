# Markdown 工作台

本文覆盖独立 Markdown 功能；通用资料库、快捷键和自动供电说明见[用户指南](user-guide.md)。设置面板按分组保存展开状态，与外层滚动位置隔离；Mermaid 源码折叠区按图表槽位单独保存，避免滚动值与展开开关的类型冲突。

工作台使用普通 `.md` 文件。编辑、预览和导出在本地运行，直接使用内置工具。

## 写作与整理

- **本文待办总览**：工具栏清单按钮或“更多操作”打开；筛选文字、显示完成数量、隐藏已完成项、直接勾选和定位到对应行。代码围栏和 YAML 属性中的示例不当作任务；只读文件可查看和定位，不能勾选。隐藏已完成项直接在待办总览中设置。
- **自定义模板**：“更多操作 → 保存为自定义模板”保存选区，没有选区时保存全文；“从模板插入”同时列出内置和个人模板。“管理自定义模板”提供预览、插入和移除。支持 `{{date}}`、`{{time}}`、`{{title}}`；同名模板分别保留，不覆盖。模板保存源文，图片和链接沿用原引用地址。
- **快速打开**：Ctrl+P 按文件名筛选资料库 Markdown，已打开的文稿排在前面；不必先回资料库。命令、标题、模板选择器都支持上下键、Enter 和 Esc，无结果时明确提示。
- **行操作**：格式栏增加行操作菜单；Ctrl+Shift+D 复制行，Alt+↑/↓ 移动行，Ctrl+Shift+K 删除行，Ctrl+Enter 切换选中任务完成状态。支持多行选区和撤销，输入法组词期间不改写正文。
- **撤销**：修正刚打开文稿、未聚焦正文时直接使用工具操作缺少撤销起点的问题；待办面板的修改可撤销、重做并正常保存。
- **查找**：选中单行文字后打开查找会自动带入，F3 / Shift+F3 切换匹配；全文搜索选中当前文稿时定位首处匹配。
- **统计**：中文按字、英文与数字按词统计，忽略空白与标点，并显示选区统计；全文统计按内容缓存，移动光标无需重新扫描全文。可在 Markdown 设置关闭。

个人模板在资料库根目录 `.markdown-templates` 中，以独立文件保存，完整资料库备份会包含它们；移除模板将文件改为 `.deleted`，不直接销毁内容。

## 已内置

| 方向 | 可用功能 |
| --- | --- |
| 编辑视图 | 块级实时编辑、源码、源码与预览分栏、只读阅读；实时编辑只替换当前源文片段，不整篇重新生成 Markdown |
| 基础编辑 | 六级标题、粗体、斜体、删除线、引用、代码、公式、列表、待办、分隔线、链接、图片；撤销与重做 |
| 输入辅助 | 括号、引号、反引号配对；代码围栏补全；列表、编号、待办和引用续写；空项回车退出；Tab / Shift+Tab 缩进 |
| 文稿导航 | 多文稿标签、可筛选命令面板、目录、快速标题跳转、行号跳转、全文检索和标签筛选 |
| 查找替换 | 上一处、下一处、大小写、完整词语、正则表达式、捕获组替换；错误表达式显示提示 |
| 阅读与排版 | 源码和代码块高亮、源码行号、正文宽度、独立的源码和阅读字号、行距、专注模式、打字机模式、全屏 |
| 表格 | 网格编辑已有表格或新建；增加和删除末行、末列；逐列对齐；转回 Markdown 并保留转义竖线 |
| 图片 | 插入文件、剪贴板图片、Ctrl+V 的图片回退、内嵌 data 图片；导入和导出源码时复制引用的本地图片 |
| 知识关联 | `[[文稿名]]`、别名与同篇标题链接；反向链接列表；正文标签与 YAML 标签；全文搜索覆盖资料库中未删除的 Markdown |
| 文稿属性 | 编辑 title、type、status、tags、aliases；其他已有 YAML 字段及注释保留 |
| 历史 | 保存修改前自动保留旧正文；可预览和恢复；恢复前另存当前内容；文件重命名后仍能找到历史 |
| 图表与公式 | LaTeX、脚注、Mermaid 12.2.0 离线渲染；支持上游 Mermaid 引擎的图表语法，可展开源码、双击缩放 |
| 演示 | 按代码块之外的 `---` 分页；全屏幻灯片、方向键翻页与退出 |
| 导出 | Markdown 与本地图片资源、HTML、TXT、原生 DOCX、PDF、PNG、JPG；保留已有目标文件直到新结果生成成功 |
| 文本编码 | UTF-8 / UTF-16；Windows 旧编码 GBK、Big5、Shift-JIS 的识别与手动重新载入；保存统一为 UTF-8 |

外部文稿默认只读。允许编辑原文件后仍需手动保存；离开、切换文稿或关闭当前标签时可以选择保存、不保存或取消。资料库文稿使用 Markdown 自己的自动保存设置。

## 设置

资料库“设置 → Markdown”和编辑器“更多操作 → Markdown 设置”共用以下 19 项常用设置。编辑器中的视图、字号、专注、打字机与同步滚动快捷调整也会同步保存。

| 分组 | 设置 |
| --- | --- |
| 编辑输入 | 默认视图、行号、高亮、符号配对、列表续写、自动保存、字数与选区统计 |
| 排版阅读 | 源码字体、源码字号、源码行距、实时编辑与预览字号、正文宽度 |
| 预览 | LaTeX、网络图片、Mermaid |
| 导出 | 默认格式、清晰度、跟随当前深浅色 |
| 本地历史 | 自动保留开关 |

源码字体、字号与行距只影响源码视图；阅读字号同时影响实时编辑和预览。网络图片开关不影响本地图片或内嵌图片。关闭历史自动保留不会删除已有版本。

## 实际边界

- 实时编辑是“点击段落就地编辑”的块级模式，当前块编辑时显示它的 Markdown 源码；不等同于 Typora 的逐字符所见即所得实现。
- Mermaid 的脚本已随包提供，不联网下载。渲染复用 Windows 已有的 Edge 或 Chrome，启动独立的无界面进程及临时配置；不控制现有浏览器窗口。单任务串行、640 MB 上限、25% CPU 上限、超时终止自己的进程树。没有这两种浏览器时保留源码并提示原因。
- 图表预览增加 650 ms 防抖，关闭文稿或继续修改后会丢弃已过时的排队渲染；已经生成的图片直接复用，导出会等待当前图表准备好。
- PDF 使用保留版式的图片页，正文没有可选取的文字层。DOCX 保留基本标题、字形、列表、表格和本地 PNG/JPEG，Mermaid 可转为图片；LaTeX 在 Word 中保留公式源码，不转换为 Word 公式对象。
- 长图受最大边长和像素数限制；过长文档提示使用 PDF。导出清晰度受这一内存保护限制。
- 编码自动识别存在歧义，可从命令面板指定编码重新载入；有未保存修改时先保存。导入读取副本，不修改原文件。
- 本地历史保留正文，不替代完整资料库备份。全文索引跳过不可读文件和超过 8 MiB 的文稿，缓存有数量上限。
- 此轮未实现 Vim、Hunspell 拼写词典、Git 远端同步、tldraw 嵌入白板、可视化关系图、复杂属性筛选视图。AI、LLM、Agent、MCP 不在本次范围内。
