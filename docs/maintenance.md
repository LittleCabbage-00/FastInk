# 代码维护与注释约定

## 阅读顺序与责任边界

入口为 `lib/main.dart` → `src/app/fastink_app.dart` / `app_shell.dart`。首页仍通过多个 part 扩展共享状态；这是现存耦合点，不等于把文件拆开就完成了解耦。后续优先向 controllers、storage、platform、widgets 的独立职责移动，不让新组件直接接管不属于它的保存或窗口生命周期。

先读 [ARCHITECTURE](../ARCHITECTURE.md) 的模块和并发约束，再查对应方法、字段注释。所有功能变更都要按[文档索引](README.md)更新对应原位置；项目根 [AGENTS.md](../AGENTS.md)保留这条工作规则。

## 参数和变量必须说明的语义

| 数据 | 约定 | 容易出错的替代方式 |
| --- | --- | --- |
| 页面显示索引 | `pageIndex` 零基；用户页码从 1 开始 | 把输入页码直接拿来访问列表 |
| 稳定页身份 | `originalPage` 用于笔迹文件归属 | 页序重排后用显示索引读写 JSON |
| 保存目标 | `inkDocument` / `inkPage` 是内存笔迹实际归属 | 加载窗口里只看 `currentPage` 保存 |
| 页面点 | InkPoint 的 x/y 按页面宽高归一化 | 把屏幕缩放后的像素写回原点列 |
| 采样压力 | 实时输入先应用当时曲线/灵敏度，保存有效压力 | 显示/导出又套一次用户曲线，或以鼠标状态污染触笔 |
| 普通笔宽 | 相对 `√(页面宽×页面高)` 归一化 | 按当前屏幕宽度或导出 DPI 直接复用旧像素宽 |
| 文本字号/排版宽 | 保存时分别相对页高/页宽归一化；编辑时还原逻辑像素 | 把紧凑输入面板的屏幕字号当最终页面字号 |
| 相机矩阵 | 文稿坐标→屏幕坐标，局部窗口再补原点 | 修改共享矩阵后逐帧叠加偏移 |
| 源文偏移 | Dart String / TextSelection 使用 UTF-16 编码单元索引 | 用 Unicode 字符数或 UTF-8 字节数替代 |
| 图像预算 | 解码尺寸为像素，内存预算字段标明 MB 或字节 | 将正文逻辑宽度误当图像解码宽度 |
| 原生资源 | 句柄/指针写清谁拥有、何时转交、何时释放 | 既交给系统又再次释放，或释放共享控制器 |

成员和全局变量注释应给出含义、单位、归属和清理/失效条件。局部变量优先解释跨坐标、缓存键、版本令牌、资源所有权和循环搜索界限；普通循环的临时索引无需用重复空话遮住算法。

## 方法注释标准

方法入口说明“做什么”，非直观参数说明“如何解释”，返回值说明空值、失败与取消。如果方法有副作用，应指出修改了哪些状态/文件；异步方法注明结果提交前的身份与代次检查。

特别注意 `_saveNow`。返回 `true` 表示当前笔迹已落盘，返回 `false` 表示有写入失败或仍有未保存的修改。切页、切换文稿、导出及依赖磁盘笔迹的页面操作需检查返回值。切页写入失败时恢复页码和视口，保留内存笔迹和撤销记录。

构造入口区分不可变参数保存、依赖注入和真正创建资源。`dispose` 要说明解除监听还是拥有资源并释放；例如虚拟视口仅解绑相机监听，不能销毁宿主共享的相机。

## 主要优化及不能破坏的约束

1. **连续视口**：页面树只覆盖当前缓冲窗口，`AnimatedBuilder.child` 复用页面，平移主要更新 Transform；跨出窗口才补建页面，中心页变化才安排装载。减少的是组件重建，不是输入采样率。
2. **活动笔迹**：新采样只追加新增线段，按宽度分桶 Path，避免每个点重算前面全部点形成近似二次开销。静态、活动、选择和光标使用独立重绘信号。
3. **缓存与瓦片**：Picture 缓存按笔画和尺寸标识，空间瓦片按修订和显示密度失效；预算按字节控制，淘汰 ui.Image/Picture 时显式释放。gutter 是采样边缘，不是允许瓦片覆盖相邻内容。
4. **文本避让**：有限占用网格与直方图单调栈先找候选，再用真实 TextPainter 测全文、二分字号。字号/宽度向下取整防回溢；结果必须装下全文并避开已有内容，不以截断文本换取“适应成功”。
5. **快速 PDF 导出**：安全时复用原 PDF，仅对修改页准备叠加；自建页另建临时段并按最终页序合并。旋转/裁切几何不安全时回退，不用屏幕低分辨率瓦片冒充完整导出。分段和后台 JPEG 编码限制内存并把重活移离 UI。
6. **封面**：文件指纹覆盖首页身份、笔迹、底图和资源。后台解析 JSON，主线程只绘制低分辨率缓存；简化只作用于预览副本。卡片裁切属于展示，不改变源页。
7. **电池调度**：Windows 约每 2 秒更新供电/节电策略；侧栏次要任务等待书写和导航空隙，同一代次合并，关闭/换文稿后旧任务失效。切回电源自动解除等待。不能以省电为由丢压力点、改旧笔迹或降低导出精度。
8. **构建保护**：公开入口用 Windows Job 限制自有进程树，进程先挂起创建、加入 Job 后才运行；系统余量不足就停止本次任务，不通过结束前台应用腾内存。
## 注释验证

纯注释修改可比较修改前后的执行代码。算法或行为变化按影响范围运行回归，用 `scripts/test.ps1` 串行执行静态分析和测试。性能说明记录样本规模、设备、测试步骤和测量结果。应用版本由 `scripts/sync_app_version.dart` 生成。
